# Fixes from the 2026-10-14 live-log investigation

1. routers/sessions.py — SessionOut requires `trigger` and `schedule_id`, but `_to_out` never passed them.
   Every GET/POST of /projects/{id}/sessions returned 500 (pydantic ValidationError).
2. db.py — postgrest-py hard-codes HTTP/2 on one client shared by all threads; after idle, bursts died with
   `httpx.RemoteProtocolError: Server disconnected`. This killed the agent's first turn before any model call.
   Session is now HTTP/1.1 with a short keep-alive.
3. main.py — unhandled 500s now carry CORS headers, so the browser shows the real message instead of "Failed to fetch".
4. services/llm_client.py — DeepSeek V4 has thinking ON by default and 400s unless reasoning_content is echoed back.
   Thinking is switched off for provider "deepseek"; api_base set explicitly to https://api.deepseek.com.
5. services/workspace_service.py — sprites-py `run()` takes `cwd`, not `dir`; every file/shell tool call passed `dir=`.
   cwd is now applied inside bash, independent of SDK keyword names. Output decoding tolerates str/bytes.
6. requirements.txt — pin openai==1.57.4 (the last build floated to openai 3.26.1 under litellm 1.55.4).
